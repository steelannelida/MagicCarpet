# Cubes

Each category file lists its cubes. An entry has a heading `## name` and states:

- the `type` string, the knob (unit, range, step) and `params`;
- the behaviour of every output as a short rule;
- how `on` is used.

| --- | --- |
| [sequencing.md](sequencing.md) | clock, sequencer, step |
| [oscillators.md](oscillators.md) | phasor, sine |
| [mixing.md](mixing.md) | mix, out |
